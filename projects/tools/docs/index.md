## Principio local-first

> 🔒 **Privacidad por diseño**
>
> Una herramienta local-first intenta procesar los datos en tu dispositivo y evita enviarlos a terceros. Aun así, revisa siempre la implementación y la política de cada herramienta antes de utilizar datos sensibles.

### Estado de las herramientas

- **Local** — el procesamiento se realiza en el navegador.
- **Sin subida de archivos** — los archivos seleccionados no se envían a un backend.
- **Sin almacenamiento** — esta colección no necesita guardar tus datos para funcionar.
